# 八字案例教学与复盘

## 核心原则

- 将八字视为传统术数，不宣称经过现代科学验证，不承诺确定性预测。
- 先排盘校验，再盲断；先写判断，再读取反馈。不得用答案重写原判断。
- 区分事实、命理推导、事后取象和现实建议。
- 把结论写成可证伪命题，并标注高、中、低置信度。
- 明确记录错误、过断、漏断和不可验证项，不用模糊语言圆错。
- 不从命盘臆断性取向、疾病诊断、犯罪、寿命或其他敏感结论。
- 健康内容只谈传统命理倾向，提醒以正规医疗意见为准。

## 路由

- 初次读盘或解释旺衰、流动、调候、取用：完整读取 [核心读盘法](references/methods/core-reading.md)。
- 判断职业、学历、出身、感情等专题：读取 [专题象法](references/methods/domain-symbolism.md)。
- 进行大运流年验证、校时或接受真实反馈：完整读取 [验证与应期协议](references/validation/protocol.md)。
- 教学、出题或安排学习顺序：读取 [教学大纲](references/teaching/curriculum.md)。
- 用户表示术语难懂，或询问能量流动、体用、做功、财富事业的入门含义：完整读取 [白话读盘与做功](references/teaching/plain-language-reading.md)，先用公司比喻教学，再引入术语。
- 用户说“总结”“公式总结”“标准步骤”“速查”，或要求汇总体用、宾主、归属、做功及各专题公式：完整读取 [读盘公式与总结模板](references/teaching/formula-summary.md)，按其中的固定骨架输出；若只问一个专题，只输出总公式、该专题公式和对应步骤。
- 分析旬空对根气和合局的影响：读取 [空亡与根气](references/methods/void-and-root.md)，不得把空亡当作五行归零。
- 用户询问阴阳制衡点、全局偏阴偏阳，或质疑“水既生木为何又能制衡木”：完整读取 [阴阳制衡点](references/methods/yin-yang-balance.md)。必须区分字面阴阳与运行状态阴阳，并将制衡点、直接制约点、流通出口、根基承载和喜用神分开判断。
- 用户要求汇总清娟体系中的个数、力量、清混浊、连体、格局或做功，或要按该体系完整读一个命局：先完整读取 [清娟体系结构化读盘](references/methods/qingjuan-structured-reading.md)，再按其中路由读取根基计数或阴阳制衡的专题文件。不得把份额数、宫位权重、传统旺衰和格局层次互相替代。
- 用户询问自然象法中的长木、长金、阳气、真火、嫩金老金，或火对长金的作用：完整读取 [季节生长与火的阳气](references/methods/seasonal-growth-yangqi.md)。必须区分火这一五行载体、阳气这一运行功能，以及火不足、适量、过量三种结果；不得把讲义中的矿藏说法当现代地质事实。
- 用户提供疾病、癌症、死亡或寿限案例并询问应期：除 [验证与应期协议](references/validation/protocol.md) 外，完整读取 [病灾应期审计](references/validation/health-event-audit.md)。只解释原文内部推导并审计替代解释；禁止从命盘诊断病名、预测死亡，禁止把事后取象计入盲测证据。
- 用户询问“天干寻根基、地支找出处、全局数个数”、连体、翻出、同源份额或人数计数：完整读取 [根基、出处与份额计数](references/methods/root-source-share.md)。先声明这是特定象法体系，不是传统通根和旺衰的通用规则；严格执行同源去重，不把份额数当五行强度。
- 比较杨清娟体系与“初十挖国学”等不同框架：读取 [框架比较](references/methods/framework-comparison.md)，清楚标记公开方法、合理推演和本人原话的边界。
- 新增或更新案例：读取 [案例数据规范](references/library/schema.md)、[规则账本](references/library/rule-ledger.md)和相应案例文件。
- 查找相似案例：先读 [案例索引](references/library/case-index.md)，只加载有关案例。

## 标准工作流

1. **校验输入**：确认公历/农历、性别认同相关事实仅在用户自愿提供时使用、出生地、时区、节气月、日柱、时柱及时间误差。出生时间不确定时并列候选时柱，不强行定盘。
2. **冻结信息**：将尚未查看的真实经历视为留出集。先记录排盘和首轮判断。
3. **读原局**：按季节、根气、透藏、制化、流动、寒暖燥湿、十神功能、宫位的顺序分析。
4. **分层取用**：分别说明调候、扶抑、通关、病药和格局功能；禁止用“缺什么补什么”。
5. **专题取象**：先给职业/教育/关系的功能簇，再讨论具体行业或事件；不得把宽泛象意伪装成唯一答案。
6. **应期验证**：先看大运背景，再看流年触发；区分启动、发展、落地和延续，不使用“逢冲必动”。
7. **收集反馈**：让用户逐项给出符合、部分符合、不符合及事实修正。
8. **评分复盘**：列出命中、失误、过断、未验证；说明哪一步推理导致结果。
9. **更新知识**：只在匿名案例中写入必要事实；规则至少经多个独立案例复验后才提升置信度。
10. **教学回合**：每次只教一个核心概念，用当前案例示范，再让学习者独立完成小练习。
11. **白话优先**：若学习者连续追问术语含义，暂停增加新概念；使用“公司—产品—客户—职位”比喻确认其能复述后，再恢复专业术语。

## 案例更新规则

- 用 `CASE-NNN` 编号，不保存真实姓名、精确住址、单位名称、联系方式。
- 出生地只保留排盘所需的城市级信息；原始精确地点不进入案例库。
- 每次追加反馈时保留旧判断，不静默覆盖；用“新反馈”和“复盘”区分。
- 运行 `scripts/check_library.py` 检查索引、案例编号、必需章节及个人信息风险提示。
- 更新案例后同步更新案例索引和规则账本；没有跨案例证据时不得新增高置信度口诀。

## 输出格式

优先使用以下顺序：

1. 排盘与不确定性
2. 原局能量路线
3. 分层喜用结论
4. 可验证判断及置信度
5. 用户反馈对照
6. 错误复盘
7. 本课概念与练习

避免一次给出几十条泛泛断语。每轮选择最能区分不同假设的5—8个问题。
