# 白话读盘与做功

## 一句话定义

- **体**：我拥有的工具。
- **用**：工具的用途，以及想取得的外部结果。
- **做功**：某个工具确实碰到目标，并使目标发生变化。
- **用神**：解决命局主要问题的五行功能；它不是体用中的“用”。

不同门派对“用”的定义略有差异。教学时先声明采用的体系，不把体用、格局用神和调候用神混为一谈。

## 公司比喻

| 十神 | 公司角色 |
|---|---|
| 印 | 知识、老师、资料、平台 |
| 比劫 | 自己、同事、执行人员 |
| 食伤 | 产品、技术、内容、方案 |
| 财 | 客户、订单、收入、商业结果 |
| 官杀 | 职位、规则、品牌、管理体系 |

完整链条：

```text
印：学习知识
→ 比劫：自己掌握
→ 食伤：做出产品
→ 财：客户付钱
→ 官：形成稳定事业和品牌
```

## 做功三问

1. 谁在干活？
2. 它对谁干活？
3. 最后得到什么结果？

常见例子：

- 食伤生财：用产品、表达、技术取得客户和收入。
- 比劫克财：用行动、团队或经营直接控制商品和资产。
- 食伤合官：靠专业输出取得岗位、责任或事业身份。
- 官印相生：单位、职位或责任带来平台、资质和专业积累。

“发生关系”不自动等于结果好。继续检查目标是否有根、得令、透出，是否受损，以及结果能否被日主承载和保留。

## 五句读盘法

初学者第一遍只回答：

1. 日主是谁？
2. 哪个十神最旺？
3. 最旺十神正在生产或控制什么？
4. 它是否连接财或官？
5. 连接后财官增强、被取得，还是被破坏？

确认学习者能复述这五句后，才加入旺衰、调候、空亡、格局和大运。

## CASE-001示范

暂用四柱：`壬申 壬子 庚辰 丁丑`。

```text
土印：知识、学历、平台
→ 金：本人和技术基础
→ 水食伤：想法、策划、产品、内容
→ 木财：客户、流量、收入
→ 火官：职位、品牌、稳定事业
```

此盘金到水强，水到木有路线但木财藏弱，木到火更弱。白话结论：生产与策划能力强于获客变现，输出强于稳定事业沉淀。

水与丁火同时有两层关系：壬丁以合绊为主，癸水对丁火有伤官克官含义。不要笼统写成“两个壬把丁火灭了”。现实上既可表现为靠产品能力取得岗位，也可表现为个人判断干扰职业稳定。
