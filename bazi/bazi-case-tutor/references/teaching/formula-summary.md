# 读盘公式与总结模板

## 使用规则

- 用户说“总结”但未限定范围时，按“总公式→四个核心概念→标准步骤→专题公式→当前案例”的顺序输出。
- 用户只问一个专题时，只给总公式、专题公式、对应步骤和一个类比，不倾倒全部内容。
- 把传统命理结论标为推演，不宣称科学因果；把事实、推演、现实建议分开。
- 体用、喜用神、十神和家里家外不得混为同一概念。

## 一、总公式

```text
某领域结果
= 宫位环境
+ 对应十神
+ 旺衰与来源
+ 生克冲合路线
+ 能否被日主调用
+ 所有权与收益权
+ 大运流年触发
+ 真实经历验证
```

白话八问：

1. 事情在哪里？
2. 由哪个十神代表？
3. 它有没有实际力量？
4. 力量从哪里来？
5. 它怎样与我发生关系？
6. 作用以后流向哪里？
7. 结果归谁？
8. 何时触发，是否有事实验证？

## 二、四个核心概念

### 1. 家里家外

```text
年月＝偏外部：家庭背景、公司、行业、社会平台
日时＝偏内部：本人、私人生活、个人项目、长期成果
```

宫位只表示远近和场景，不直接决定所有权。年月食伤可以是本人在公司公开发挥的能力；日时之物也可能是负担、共同资源或尚未取得的对象。

### 2. 我的与外部的

按四层产权判断：

```text
来源权：谁产生？
使用权：谁能调用？
所有权：谁能处置？
收益权：最后谁获益？
```

判断口诀：

> 位置看远近，来源看谁产生，关系看谁调用，流向看谁获益，现实合同确认产权。

断电测试：如果明天离开家庭、公司或平台，该能力或资源还能否合法、稳定、独立使用？能保留的部分才可纳入自己的体。

### 3. 体用

```text
体＝当前问题中已经拥有并能发动的主体、能力和工具
用＝体要处理、取得、改造或完成的对象
做功＝体实际作用于用并使其发生变化
成果＝做功后真正回到命主的部分
```

体用是句法角色，不是十神永久标签。同一个印星在学习前是要吸收的“用”，内化为方法后可成为职业能力之“体”。财官不是天然的用，食伤也不是天然的体。

### 4. 外部如何进入体

```text
外部资源
→ 与日主建立有效连接
→ 被吸收、掌握或取得控制权
→ 能独立重复使用
→ 脱离原平台仍可保留
= 进入体
```

知识靠学习内化；规则靠实践转成自律和管理；财富资源要取得合法控制权；公司流量、客户和数据库不会因接触过就自动进入个人之体。

## 三、能量动作词典

| 关系 | 动作语言 | 核心问题 |
|---|---|---|
| 生 | 供应、输出、转化 | 谁付出，谁得到？ |
| 克 | 管理、约束、改造、取得 | 克得动吗，取得后归谁？ |
| 合 | 吸引、绑定、占用、重组 | 是合绊还是有条件合化？ |
| 冲 | 撞开、移动、替换、释放 | 改变了什么，谁更受伤？ |
| 刑 | 内部失调、反复摩擦 | 哪个环节长期不协调？ |
| 穿/害 | 暗中损坏接口 | 信任或配合怎样受损？ |
| 破 | 结构松动、计划裂开 | 什么难以维持完整？ |

发生关系不等于做功成功。继续检查力量、位置、路线、承载和结果归属。

### 阴阳制衡点

```text
阴阳制衡点
= 全局主导运动的相反必要功能
× 原局载体
× 根基出处
× 实际连接
× 承担能力
```

标准步骤：找成势 → 定向外或向内 → 找反向功能 → 查原局载体 → 寻根基出处 → 比较力量 → 双轴复核 → 分层取用。

必须区分：

- 字面阴阳与运行状态阴阳；不能数阴干阳干定全局。
- 状态制衡与五行克制；水可在状态上与木相反，同时在生克上继续生木。
- 制衡点、直接制约点、流通出口、根基承载点和喜用神；五者可以不同。

详细方法与 `丁卯 壬寅 壬辰 癸卯` 示例见 [阴阳制衡点](../methods/yin-yang-balance.md)。

## 四、标准读盘步骤

1. **校验排盘**：历法、地点、时区、节气、时辰误差、四柱和大运。
2. **限定问题**：先确定出身、学习、职业、财富、关系或应期，避免体用漂移。
3. **定宫位与角色**：谁是主体，谁是对象，事情偏家里还是家外。
4. **看月令调候**：确定季节主气与寒暖燥湿。
5. **清点力量**：透干、藏干、本中余气、通根、得令、生扶、空亡。
6. **看明面关系**：先处理生克合冲刑穿破、三合三会，再看暗夹暗拱等低权重关系。
7. **画流动路线**：谁生谁、谁克谁、谁被合绊、力量停在哪里。
8. **判断做功**：体是否碰到用，是否产生现实价值。
9. **判断归属**：区分来源权、使用权、所有权和收益权。
10. **分层取用**：分别说明调候、扶抑、通关、病药、格局和体用，不用“缺什么补什么”。
11. **叠加岁运**：原局是结构，大运是背景，流年是触发；区分启动、发展、落地、延续。
12. **反馈复盘**：列事实、推演、命中、失误、未验证和替代解释。

优先级：

```text
月令与强根
＞透干和明确生克合冲
＞普通根气与宫位
＞空亡墓库等修饰
＞暗夹暗拱、虚神和特殊外格
```

### 清娟体系专项顺序

```text
寻根基与出处
→ 同源去重数份额
→ 时令、宫位、根源、组合定力量
→ 判断清混浊
→ 找连体、贵字与病字
→ 判断阴阳主势和制衡点
→ 定体用
→ 画做功路线
→ 查结果归属与根基代价
```

四个概念不得混算：

```text
份额＝独立来源或作用层次
力量＝得时、得位、得源、得势后的发动能力
清混浊＝来源品种与自然表达是否一致
格局＝主势、承载、制化、体用和结果组成的整体结构
```

完整说明见 [清娟体系结构化读盘](../methods/qingjuan-structured-reading.md)。

## 五、专题公式

### 出身

```text
出身
= 年月环境
+ 父母星状态
+ 财官印配置
+ 家庭资源能否流到日主
+ 命主实际获得程度
```

分别判断经济、照顾、教育、规则、社会资源，不用一个“好/差”概括。

### 学习与学历

```text
学习结果
= 印星输入
+ 日主吸收
+ 食伤输出
+ 官杀目标与考试规则
+ 岁运触发
```

### 能力

```text
能力
= 日主基础
+ 印星输入
+ 食伤输出
+ 是否有根有源
+ 是否被现实反复验证
```

### 职业

```text
职业类型
= 主要能力链
+ 年月行业环境
+ 财官落点
+ 社会为何支付报酬
+ 经历验证
```

### 事业

```text
事业
= 能力系统
+ 平台与责任
+ 市场成果
+ 规则和组织能力
+ 能否长期固化
+ 事业岁运
```

### 财富

```text
财富
= 价值生产
+ 财星质量与来源
+ 市场成交
+ 日主控制能力
+ 所有权和收益权
+ 留存与扩大
+ 财运触发
```

财星是市场和可经营资源接口，不等于账户余额；无明财也可通过食伤、官杀、印星或比劫代表的渠道获得现实报酬。

### 创业

```text
创业闭环
= 产品能力
+ 客户与渠道
+ 现金流
+ 资源控制权
+ 规则管理
+ 风险承受
+ 小规模验证
```

### 感情

```text
关系模式
= 日支环境
+ 双方功能与需求
+ 生克合冲方式
+ 工作与私人领域的边界
+ 共同利益和规则
+ 岁运触发
```

现代关系不机械套用异性婚姻的单一配偶星。

### 搬迁

```text
迁移
= 年月日时的内外连接
+ 宫位受冲合
+ 原环境承载变化
+ 岁运触发
```

### 健康倾向

```text
传统体质倾向
= 五行偏枯
+ 寒暖燥湿
+ 受损路线
+ 岁运重复
+ 医学事实校正
```

不得由此诊断疾病。

## 六、CASE-001固定示范

暂用 `壬申 壬子 庚辰 丁丑`，时辰存在约前后两小时误差，因此时柱相关判断降级。

```text
土印：知识、方法、经验
→ 庚金：判断、筛选、执行主体
→ 壬癸水：分析、策划、产品输出
→ 乙木财：客户、市场、收入与资源
→ 丁火官：岗位、规则、品牌与长期事业
```

归属分层：

- 日干庚：最明确的主体。
- 辰中癸：偏内部思路；丑中癸因时辰误差降级。
- 月令子：偏行业信息、公司需求和外部任务场。
- 年月壬：兼具外部场景与本人社会化输出的双重属性，不能一概判为“别人的水”。
- 申子辰：表示外部环境与内部能力高度耦合，不代表公司资源自动归个人。
- 辰中乙：隐藏的市场和财富接口；木弱表示直接商业承接不显，不等于财富上限低。
- 丁：职业规则和长期结构；是否稳定发挥受时辰误差及旺水环境影响。

本案主线：

```text
外部平台提供信息、任务和场景
+ 本人提供判断与产品能力
→ 形成方案和商品
→ 市场验证
→ 公司或个人取得销售
→ 命主实际得到工资、利润、产权、经验中的一部分
```

已反馈的职业路径可用于说明从金的技术执行，转向水的产品策划，再靠近木的跨境市场承接；不得把事后对应升级成所有类似命局的确定规则。

## 七、默认总结输出骨架

用户只说“总结”时，输出：

1. 一句话总公式。
2. 家里家外、归属、体用、做功四个定义。
3. 十二步标准流程。
4. 用户当前追问所涉及的专题公式。
5. 当前案例的一条能量链和归属表。
6. 三项最重要的不确定性或禁用误区。

默认避免重新输出全部长篇课程；用户要求“完整版”时再展开所有专题公式。
