# CASE-005

## 状态与隐私

- 匿名方法案例，来源为公众号法本第7篇“全局数个数”答疑。
- 原文主要讲算法，没有提供可验证的人生反馈。
- 婚姻与西瓜比喻只用于解释实体和分身，不登记为现实断语。

## 排盘

- 四柱：辛卯、丙申、庚申、辛巳。
- 年月为家外，日时为家里。
- 丙申同柱天地一气，丙克申而非丙生申。

## 留出信息

无现实经历、婚姻次数、职业、地域或岁运反馈。

## 预先判断

只冻结原文算法：

```text
丙火三份＝月干明丙＋家外年卯生巳翻丙＋家里时巳翻丙
丙不生申＝三份丙共用一个月申，形成三个柱内分身
辛金三份＝家外月申翻辛＋家外卯生巳中庚翻辛＋家里辛申巳合并一份
```

## 真实反馈

原文未提供现实反馈，只说明该算法可用于婚姻、合作人数、团队和份额等细节。

## 评分与错误

- 无盲测，不能证明三次婚姻或三人团队。
- 容易犯的错误一：把月申三个分身当成三个独立申实体。
- 容易犯的错误二：把卯生巳改写为“第二个月申”。
- 容易犯的错误三：只按最终落点把家外卯所生的巳并入家里。

## 可复验假设

- 来源归属可以保留上游宫位身份：家外卯所生的巳与家里原有时巳分别计。
- 同柱天干不生坐支时，多份天干产生坐支分身而非独立实体。
- 同柱天干生坐支时，多份天干可能产生多个独立坐支实体；须用未知答案案例验证。
- 人数、婚次和团队数量必须先冻结算法，再读取反馈。

## 教学价值

- 六种数量：本体、路线、份额、分身、实体、动态个数。
- 家里合并规则的来源归属例外。
- `丙申`共用地支与假设的`戊申`生出地支之区别。
- 时干辛三条正确路线。
