## 原文结构复盘

### 自然象法

```text
戌月长金
→ 三戌为燥土矿床，庚透为矿藏浅露
→ 丙午及戌中丁形成强阳气
→ 日主庚受到贴身火的过量加工
→ 月干庚相对远离丙，却生年干壬而向水泄出
```

作者据此形成“有矿藏，但两个庚分别被火制过和向水化泄，不能完成长金”的图景。它属于体系内自然隐喻，不是现代地质判断。

### 病灾应期原文

```text
原局庚被丙午火制过
→ 午运重复激活庚午
→ 辛丑年来金与丑库
→ 丑与三个戌刑、与午穿/害
→ 作者认为根库受损、天干金再受火
→ 已知乳腺癌后，以庚生壬食神、食神取乳汁，反推庚为乳腺
```

## 评分与错误

- 无事前判断，不能计算命中分数。
- 可复核结构：丙克庚、丑戌刑、丑午害/部分体系称穿、辛坐丑有根。
- 术语问题：戌中不藏庚；丙辛传统首先论合；“丙冲庚”“丑库连根毁掉”属于非标准或过强表达。
- 过断：由庚生壬、食神分泌唯一锁定乳腺癌；由午运辛丑年直接锁定死亡。
- 替代解释未被排除，同样的火金土关系可被映射到压力、岗位、资源、家庭或其他身体象，故病名对应属于结果导向选择。

- 不保留“庚受火克＋丑戌刑＝乳腺癌”或“午运辛丑＝死亡”等病名、寿限规则。

## 教学价值

- 区分火这一载体与阳气这一功能，以及阳气适量炼金、过量制金。
- 理解戌月嫩金、丑月老金和浅层矿藏只是特殊季节隐喻。
- 区分传统藏干与“矿藏翻出”的特殊出处映射。
- 学习原局—大运—流年的应期分层。
- 识别器官病名的事后取象、术语混用和寿限过断。
