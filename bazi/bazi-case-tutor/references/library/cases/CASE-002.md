# CASE-002

## 状态与隐私

- 匿名教学案例；仅保存四柱和经泛化处理的职业反馈。
- 未提供出生日期、性别、出生地和时间误差，不做历法复核、校时或地域得气结论。
- 本案例来自用户提供的清娟体系讲解，属于“反馈支持的结构重建”，不是完整盲断实验。

## 排盘

- 四柱：癸丑、甲子、壬寅、辛丑。
- 月令子水，冬季寒湿；双丑承载，日支寅中藏甲、丙、戊。
- 按用户提供的宫位力量规则，年支与日支各1%、月支50%、时支48%；该百分比是体系特定规则，尚待独立来源与跨案例验证。
- 按该体系成象：子、丑为旺点；壬水环境近似冰冷水域，寅木在丑土承载下休眠，寅中丙火作为续命动力。

## 留出信息

缺少可冻结的首次访谈记录。已知反馈仅包括：命主工作组织的类型、层级和服务功能。家庭、学历、关系、健康、迁移及岁运事件均未知。

## 预先判断与反馈摘要

| 判断层级 | 内容 | 证据状态 |
|---|---|---|
| 结构判断 | 子水与丑土构成主要环境，寅木与寅中丙火连体，丙火量小但承担冬木续命功能 | 用户提供体系内推导，未独立盲测 |
| 功能判断 | 家里寅木翻出月干甲木到家外，较适合解释为向外部人群提供疏导、培训、救济、保护或权益支持 | 可作为以后案例的宽口径预判 |
| 组织判断 | 更像事业单位、群团协会、国企或公共服务平台，不宜只凭原局唯一锁定公务机关 | 反馈后重建，精度待验证 |
| 层级判断 | 月支可取工作单位，年上丑可取上级或总部，时支丑旺点可辅助提出较高区域层级 | 反馈后重建；不能仅凭此锁定省级 |
| 真实反馈 | 命主在省级群团组织工作，职责主题涉及职工权益维护和困难帮扶 | 与“救济、保护、公共服务”功能簇相符 |

## 真实经历

- 已知职业反馈：在省级群团组织任职，机构功能包括维护职工权益、帮扶困难职工。
- 未保存单位名称、岗位名称或其他可识别信息。

## 评分与错误

- 功能象“帮助、救济、权益保护”与职业反馈一致，但分析发生在反馈已进入材料之后，不能计为严格盲断命中。
- “省级单位”的判断依赖年、月、时宫位及双丑旺点的事后组合，现阶段只能列为低置信度假设。
- “清贵格局不是当官就是富人”过于绝对；本案例只能支持结构一致性与公共服务功能，不能证明必富必贵。
- “木运必因诱惑而失败”“南方必减贵”等结论没有本案例岁运和地域反馈，不得写成事实。
- “仙草命”是把高寒、清、活木和救济功能合成的教学意象，不是职业或财富等级的独立证据。

## 可复验假设

- 先从寅丙连体提取“续命、救济、提供动力”，再映射到公共服务功能，可能比直接猜具体行业更稳定。
- 家里资源翻到月干家外，若同时服务旺水比劫环境，可优先询问培训、权益、公益、医卫、应急或组织服务工作。
- 旺点与贵点分离：子丑代表环境和数量，寅丙代表不可替代的生命价值；需要新案例验证该区分是否提高预测力。
- 根源计数与清混必须逐条画出来源，库土只作根基时不直接计成目标之气；不同来源是否合并应由真实功能验证。
- 冬木遇木运的结果取决于阳气、土的承载和来源清混，不能预设扩张或感情、投资诱惑必败。

## 教学价值

- “根基、出处、个数”与表面数同字的区别。
- 家内外计数和库土不直接计为目标气的边界。
- 清混描述结构一致性，不等于永远心理清醒。
- 旺点、太极点与贵点各自回答不同问题。
- 阳气、真火、温度三个概念不可混用。
- 从“冰海—休眠木—续命火”的自然图景提炼社会功能，而非一步猜单位。
- 已知反馈后的漂亮解释必须标成重建，不能伪装成盲断命中。
