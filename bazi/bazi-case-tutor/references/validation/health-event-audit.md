# 病灾应期审计

## 安全边界

- 八字属于传统术数，不能诊断癌症、确定器官病变、判断寿命或预测死亡。
- 用户提供已发生的病灾或死亡反馈时，只能分析原文内部如何建立对应，并明确标为事后取象。
- 现实健康风险、筛查、诊断和治疗以正规医疗机构与医生意见为准。

## 一、分开四个层次

```text
原局结构弱点 ≠ 医学病灶
大运重复或加压 ≠ 必然发病
流年关系触发 ≠ 唯一事件类型
已知病名后的器官对应 ≠ 事前预测能力
```

应期教学可以使用三层框架：

```text
原局＝长期结构与候选薄弱环节
大运＝多年背景、重复或持续加压
流年＝具体年份的新增连接和触发
```

三层同时出现只能提高“该结构被激活”的假设，不能唯一推出病名、严重程度或死亡。

## 二、审计步骤

1. 冻结作者在得知反馈前是否已有具体预测；没有记录则视为事后解释。
2. 列出原局真正明确的生克、根气和寒暖关系。
3. 列出大运带来的重复、伏吟或持续背景，不把“某字到”写成必然寿限。
4. 列出流年的天干关系、地支刑冲合害，并使用标准术语复核。
5. 检查特殊体系的“翻出、连根毁坏、冲克”等是否混入传统藏干或六冲概念。
6. 罗列同一组合可对应的至少三个现实领域，防止唯一归因。
7. 判断器官、病名和死亡是否在得知事实后才被选中。
8. 将案例标成预先判断、部分预先判断或纯事后取象；只有前两者才能按协议评分。

## 三、CASE-002应期原文的内部路线

命局：`壬戌 庚戌 庚午 丙戌`。反馈材料称命主在午火大运辛丑年因乳腺癌去世。

作者的内部推导为：

```text
原局：日主庚坐午、邻丙，庚被火制过
→ 午运：重复激活庚午及火对庚的压力
→ 辛丑年：辛坐丑带来金与金库
→ 一个丑与三个戌刑，又与午穿/害
→ 作者称金根库受损，天干金再受火
→ 已知反馈后，以庚生壬食神、食神取乳汁，反推庚为乳腺
→ 对应乳腺癌与死亡
```

白话类比：原局机器零件已经处于高温；午运提高持续温度；辛丑年带来补给仓，但补给仓同时进入刑穿网络，于是作者认为零件和根基一起失稳。

## 四、术语复核

- 戌藏戊、辛、丁，不藏庚。“戌中庚跑出”是特殊矿藏映射，不是传统透藏。
- 丑藏己、癸、辛，辛丑属于辛有根。
- 丑戌属于三刑体系的一部分；一个丑对三个戌表示关系重复，不等于物理上把丑库毁灭。
- 丑午通常论害，部分象法称穿；应同时标注体系。
- 丙克庚成立；丙与辛传统上首先有丙辛合，不能笼统写成丙火冲克辛。
- “午到庚也到”应翻译为午运激活原局庚午关系，不是大运凭空增加一个庚。
- “弱庚不喜见丑根”不是普遍规则。原文实际想表达的是根库一到便进入刑穿网络，形成“引根受制”的特殊假设。

## 五、为何乳腺对应属于事后取象

原文路线为：

```text
庚生壬
→ 壬对庚为食神
→ 食神可取饮食、分泌
→ 乳汁是分泌物
→ 反推庚为乳腺
```

这条路线不能事前唯一锁定乳腺，因为食神还可取表达、产品、子女、享受等，壬水也有大量其他象意，不同体系对身体部位的五行映射亦不统一。得知乳腺癌后才从象意库选择乳汁，属于结果导向选择。

禁止生成以下口诀：

```text
庚受火克＋丑戌刑＝乳腺癌
午运＋辛丑年＝死亡
```

## 六、案例证据等级

- “午运辛丑年因乳腺癌去世”：用户转述的实际反馈，事实来源尚未独立核验。
- 原局、大运、流年组合复核：可检查的命理结构描述。
- 庚对应乳腺、午运为寿限、辛丑为死亡应期：纯事后解释，不能评分为预测命中。
- 此案例只能教学应期分层、术语审计和事后取象风险，不得提升任何病名或寿限规则的置信度。
