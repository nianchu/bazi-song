# 验证与应期协议

## 盲断协议

1. 冻结已知信息，只保留排盘必需资料。
2. 记录5—8条可验证判断，每条标注置信度和推理链。
3. 用时间窗口而非单点强猜；说明候选事件领域。
4. 收到反馈后原文保留“符合/部分/不符合/未验证”。
5. 将“没发生”视为有效反证。

## 评分

- 2：具体且符合。
- 1：方向符合但有过断或时间偏差。
- 0：不可验证或过于宽泛。
- -1：明确错误。

同时报告命中率不可取；案例量小时报告分项得分和主要错误类型。

## 校时

- 列出相邻候选时柱及时间范围。
- 选取能区分候选盘的年份，不用所有盘都能解释的共同事件。
- 真太阳时仅在接近时辰边界时作为修正之一。
- 父母回忆存在误差时保留概率式倾向，不伪装成确定结论。

## 规则升级

- 单一案例：仅作假设。
- 2个独立案例同向：低置信度规则。
- 3—5个独立案例且有反例检查：中置信度。
- 6个以上跨背景案例、预先注册判断且表现稳定：才可考虑高置信度。

每条规则记录支持案例、反例、适用前提和最近更新时间。事后取象不得计入盲测证据。
