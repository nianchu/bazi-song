# 空亡与根气

## 使用原则

1. 先按日柱所属旬确定旬空。
2. 空亡不等于该支不存在或藏干全部归零。
3. 将空亡理解为落实程度、稳定性或可用性打折。
4. 再检查得令、透干、合会、冲填及岁运是否使该支发挥其他功能。
5. 不把“旺不为空、合不为空、冲实”等不同门派口诀无条件叠加；选择一致规则并用案例验证。

## CASE-001

庚辰日属甲戌旬，申酉空。年支申因此不能按普通禄根满额计算。

同时，申在子月参与申子辰水势，天干又透壬水。较稳妥的写法是：

```text
申作为庚根的落实程度打折；
申作为生水来源的功能仍然明显。
```

所以庚金比普通“庚见申”更弱，但丑中辛金、辰丑印星仍提供一定承载，暂不据此直接定从格。
