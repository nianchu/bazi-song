# 核心读盘法

## 一、固定顺序

1. 校验年、月以节气为界，核对日柱和时辰边界。
2. 看月令，定寒暖燥湿和季节主气。
3. 查每个天干是否得令、得地、有根、受生、受制。
4. 查地支藏干、透干及合冲刑害是否改变原始功能。
5. 找全局力量源头、承接路线、堵点和最终落点。
6. 判断日主为有根/无根、能否承载，不先追求单一强弱标签。
7. 把十神作为功能：印输入、比劫协作竞争、食伤输出、财结果、官杀规则责任。
8. 最后才看宫位与具体象。

## 二、能量流动

用“源头 → 承接 → 输出 → 结果”描述，不使用物理学意义的能量。

检查：

- 源头是否得月令、透干、有根。
- 承接者是否真实存在、能否承受上游力量。
- 是否被合走、冲坏、重克或因合局改变功能。
- 两股力量相战时有无通关。
- 最终落在哪个十神、宫位和现实功能。

## 三、强弱

禁止数五行个数。一个得令、有根、透干的字可强于数个虚浮字。给出结构化结论，例如：“日主有根、不从；不得令且泄重；能承载但需要印比支持。”

检查根气时同步检查旬空及合局倾向。空亡不等于该支归零；写成“根气落实程度打折”，再判断该支是否仍通过得令、透干、合会或岁运发挥其他功能。详见 [空亡与根气](void-and-root.md)。

## 四、调候与取用

分开回答：

- 调候：寒暖燥湿能否正常生发。
- 扶抑：日主是否需要生扶或泄制。
- 通关：交战双方能否转为连续相生。
- 病药：全局最大结构问题及解决功能。
- 格局：关键十神如何维持目标结构。

“缺”只表示表面未出现；“喜”表示某功能能改善结构；“用”必须注明采用的体系。

## 五、组合判断

- 合局只描述趋向，检查月令、透干、阻碍和参与支是否仍保留原功能。
- 合、冲、刑、害表示关系被触发，不自动等于吉凶或大事。
- 同一触发只优先落在一个有现实条件的领域，不把所有象同时兑现。
- 大运是背景，流年是触发；区分启动、发展、落地、延续。
