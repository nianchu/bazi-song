# 框架比较

比较在公开资料中可识别的方法，不冒充老师本人断盘，不将推演写成本人原话。

## 杨清娟体系

公开材料强调：成势看开关、自然成象、体用做功、家里家外、天干寻根；以印比食伤禄为体，以财官为外部目标，观察身体哪个部分与财官发生关系。

应用问题：

1. 哪种五行已经成势？
2. 哪些字属于体，财官在哪里？
3. 哪个体通过生、克、合、制取得财官？
4. 功是否真实、结果大小如何、开关何时被岁运触发？

用户提供的“寻根基、找出处、数个数—清混真假—旺点、太极点与贵点—自然成象”扩展工作流，见 [清娟自然成象工作法](qingjuan-natural-imagery.md)。其中宫位百分比、家内外计数和季节使命等尚未由本库独立核对为公开原话，应用时必须标明来源层级。

## 初十挖国学

公开视频强调古籍考据、五行动态关系、月令与格局、十神非固定吉凶，并区分身强弱、格局、扶抑、病药和调候；反对用“身弱不担财”等单一口诀判死。

应用问题：

1. 月令和全盘气势如何？
2. 格局、强弱和调候分别回答什么问题？
3. 财是否为日主可控制、经营的对象，而非只看数量？
4. 大运流年怎样改变原局关系？

## CASE-001交集

两种框架均可看到：水势与食伤输出突出，财官承接偏弱。杨清娟式重点是“旺食伤怎样取乙财、丁官”；初十式重点是“不能因财藏、身偏弱直接判贫，要区分动态财路与调候”。
