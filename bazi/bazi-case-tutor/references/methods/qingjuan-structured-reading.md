# 清娟体系结构化读盘

## 适用边界

本文件把用户提供的讲义片段与已讨论内容整理为可执行框架。它用于学习和复盘特定象法体系，不代表原作者完整课程，也不把合理推演冒充老师原话。传统子平的通根、旺衰、格局与本体系的“根基、出处、个数、清混浊、宫位力量”必须分栏处理。

专题细则：

- 寻根基、找出处、全局数份额与同源去重：读 [根基、出处与份额计数](root-source-share.md)。
- 全局状态阴阳与制衡点：读 [阴阳制衡点](yin-yang-balance.md)。
- 传统月令、能量流通和分层取用：读 [核心读盘法](core-reading.md)。

## 一、先分清四种问题

| 层次 | 核心问题 | 不能替代什么 |
|---|---|---|
| 个数/份额 | 有几个独立来源、外现层次或作用份额？ | 不等于五行力量，也不自动等于人数 |
| 力量 | 谁得时、得位、得势，谁真正能发动？ | 不等于纸面个数 |
| 清混浊 | 来源和全局表达是否同类、同季、同一方向？ | 不直接等于吉凶或贵贱 |
| 格局/做功 | 主体用什么路线处理对象，最后形成什么结果？ | 不等于找到一个旺字或喜用神 |

必须按“先来源、再力量、后结构、终看做功”的顺序，避免用一个答案包办所有层次。

## 二、完整读盘总流程

```text
校验四柱
→ 定季节与自然状态
→ 天干寻根基
→ 地支找出处
→ 同源去重数份额
→ 宫位与时令定力量
→ 判断清、混、浊
→ 找连体和核心根基
→ 判断全局阴阳主势与制衡点
→ 定体、用和宾主
→ 画做功路线
→ 看结果是否落地并归我
→ 岁运触发与案例验证
```

## 三、个数：数的是独立份额，不是字面笔画

### 基本原则

```text
有效份额
= 台面独立来源
+ 家里向外投射的独立来源
- 已经计入的同源重复
```

- 天干寻根基：追踪台面天干由哪个地支、藏干或生化节点支撑。
- 地支找出处：追踪外现地支是否由家里库源翻出。
- 同一个家里源头可以有多条外现路线，但计算同一目标时只能报账一次。
- “翻出”是本体系的来源映射，不等于传统藏干中真的藏着一个完整地支。

固定例 `丁卯 壬寅 壬辰 癸卯`：

- 卯木可按“年支明现卯＋辰中乙翻出卯”计两份。
- 月柱壬寅可分别呈现台面一层和辰源向外投射一层，所以讲义称“壬寅两个”。
- 丁火份额可由明卯所生、辰源翻卯所生、家外明寅中丙火翻出构成三份。
- 辰源若已经通过卯路线计入丁，再通过其投射寅中的丙重复计丁，必须删除。

详细推导只保存在 [根基、出处与份额计数](root-source-share.md)，这里不再展开。

## 四、力量：数出来多，不代表能量大

力量至少检查四层：

1. **时令**：是否处于季节旺点，是否符合自然生长或收藏阶段。
2. **宫位**：采用的特定体系是否给月、时、年、日支不同权重。
3. **根源**：有几个真实独立根基，还是多个表象共用一个薄弱源头。
4. **结构增减**：是否连体、成势、得生，或受到克、泄、合绊、冲穿和承载破坏。

用户提供的讲义口径为：

```text
年支1%　月支50%　日支1%　时支48%
```

该数字只作为此体系的宫位模型，不应伪装成所有命理门派认可的客观测量。即便使用该模型，也要考虑天干出处互相占有、同源重复和季节状态，不能机械相加后直接断吉凶。

固定例中，寅占月位50%、时卯48%、年卯1%，木在春季旺点并占主要宫位，所以木势显著；辰虽为全局共同根源，但日支宫位仅1%，呈现“源头重要而承载薄”的矛盾。

## 五、清、混、浊：看来源品种与自然表达

### 工作定义

- **清**：某一台面表达能追到一个品种或同一自然方向的来源，主线一致。
- **混**：天干同一功能背后出现两个以上不同品种、不同方向的来源。
- **浊**：地支根基或自然承载中出现品种、季节形态或表达方向不一致。

“品种”不能只理解成五行名称，还要结合阴阳、季节阶段、来源路径和该体系对“长木、长金”等自然类别的划分。

### 同季同向的例外

若多个来源都服务于春夏长木，或都服务于秋冬长金，虽然字面品种不完全相同，但其自然方向与命局表达一致，可以按该讲义定为清，不一定判混浊。

判断公式：

```text
是否清
= 来源是否独立
+ 品种是否同类
+ 是否处于同一季节生化方向
+ 最终表达是否一致
```

### 固定例

- 年干丁火虽可联系寅中丙火，但相关火的上游都可追到同一辰源所发动的木势；按讲义逻辑，火的表达主线一致，可定为清。
- 命局处寅月，讲义认为该时段自然土壤应呈丑土的本有样子，而盘中承载呈辰土，因此把土判为混浊。

第二条属于该体系特殊的自然季节映射，现有材料不足以推出完整的月份—土壤判表。遇到其他月份不得自行类推，除非获得原规则或更多案例。

## 六、连体、根基与“贵字病字”

### 连体

连体不是单纯相邻，而是主体与某地支、禄根、暗禄或共同来源形成紧密生命线。判断时检查：

- 日主是否从该支获得根基或暗中同类。
- 该支是否同时承载全局其他字的出处。
- 该支受伤时，是否会同时影响主体和整条生化路线。

### 贵字与病字

- **贵字**：全局赖以成立、翻出、承载或完成做功的关键节点。
- **病字**：该节点本身薄弱、受制过度、堵塞或一旦失效就拖累全局。

同一个字可以既贵又病：重要性回答“不能没有谁”，健康度回答“它能否承受”，两者不是矛盾。

固定例中：

- 辰藏癸，与壬日主形成暗中同类联系，并作为壬癸水及寅卯木追溯的共同源头，因此是关键根基。
- 木势极强，辰既向外供给水木路线，又承受旺木克、穿或消耗；在该宫位模型中自身仅1%。
- 所以辰使全局成立，是贵字；辰又薄弱且被过度使用，是病字。

“辰随时崩塌”应翻译为结构语言：核心承载节点负荷过大，遇到进一步伤辰或强化木势的岁运，相关路线更容易失衡。不得把“崩塌”直接具体化为灾祸。

## 七、格局：不是五行数量排行榜

这里把格局分成三个层次，避免混用：

1. **季节格局**：月令主气提供什么舞台和基本秩序。
2. **结构格局**：全局哪股力量成势，谁承载、谁制衡、谁是出口。
3. **做功格局**：体通过什么动作取得或转化用，结果能否归到命主。

结构化公式：

```text
格局有效度
= 月令与主势
+ 根基承载
+ 制化与流通
+ 体用能否接触
+ 结果能否落地
- 核心病点造成的折损
```

不应因为某五行占99%就直接称格局高，也不能因为根基只有1%便直接断人生层次低。成势可能带来强输出，根弱可能带来承载和持续性问题；要看二者怎样共同作用。

## 八、阴阳制衡：看运行方向，不数阴阳字

- 先找全局主导运动是向外扩张，还是向内收藏。
- 再找承担相反必要功能的原局载体。
- 检查该载体的根基、连接和承担能力。
- 同时复核五行生克轴：状态相反不等于五行必然相克。

固定例中，春季寅卯木代表强烈生发扩张，壬癸水代表润下收藏，因此水承担状态上的阴阳制衡；但在生克轴上水又生木，所以弱水根可能被旺木持续抽取。详细规则见 [阴阳制衡点](yin-yang-balance.md)。

## 九、体、用与做功

### 体用

```text
体＝当前问题中已经拥有、能够发动的主体和工具
用＝体需要处理、取得、改造或完成的对象
```

印比食伤禄常被该体系优先视作身体与能力系统，财官常作为外部目标，但这只是起点，不是永久标签。必须结合宫位、来源权、使用权、所有权和实际问题重新确认。

### 做功

```text
做功
= 体真实接触用
+ 通过生、克、合、制、化等动作使其变化
+ 形成可落地结果
+ 结果有一部分归命主
```

只发生生克合冲，不等于做功成功。继续检查：

- 谁发起动作，谁承担成本？
- 体有没有力量碰到用？
- 路线中间是否堵塞或反伤根基？
- 结果是名义接触，还是获得使用权、收益权或所有权？
- 做功能否重复和持续？

### 固定例的主路线

```text
辰中癸
→ 壬壬癸（水的主体、储备或表达基础）
→ 寅卯木（输出、扩张、项目化）
→ 丁火（结果端、财的接口）
```

可概括为比劫生食伤、食伤生财的连续输出路线。但必须同时记录副作用：旺木持续使用并给共同根基辰施压，所以“能做事”和“能否长期承载”需要分开判断。

## 十、固定案例整合表

命局：`丁卯 壬寅 壬辰 癸卯`

| 项目 | 结构化结论 |
|---|---|
| 季节主势 | 寅月春木生发 |
| 宫位力量 | 寅50%、时卯48%、年卯1%、辰1%（仅按讲义模型） |
| 个数 | 按来源份额计数并同源去重，不等于力量 |
| 火之清混 | 火的上游表达归于同一木势与辰源，按讲义定清 |
| 土之清浊 | 寅月自然土壤与辰土表达不一致，按讲义定浊；规则外推受限 |
| 连体根基 | 日主与辰中癸暗中相连，辰又是全局共同源头 |
| 主导运动 | 寅卯木向外生长扩张，状态偏阳 |
| 制衡点 | 壬癸水承担收藏储备，但共同辰根薄弱 |
| 流通出口 | 木生丁火 |
| 主做功 | 水生木、木生火 |
| 核心病点 | 全局依赖辰，旺木又消耗或制辰，承载与持续性受压 |

## 十一、输出模板

分析同类命局时按以下格式输出：

1. **体系声明**：哪些是传统规则，哪些是清娟体系特殊口径。
2. **来源表**：每个天干根基、每个地支出处、同源关系。
3. **份额表**：台面、家里投射、去重项和最终个数。
4. **力量表**：季节、宫位、根源、组合增减分别说明。
5. **清混浊**：说明“什么品种、来自哪里、为何同向或异向”。
6. **核心结构**：连体、贵字、病字和承载关系。
7. **阴阳制衡**：主导运动、反向功能、载体和落实程度。
8. **体用做功**：主体、对象、动作、出口、结果归属和副作用。
9. **格局结论**：优势、病点、成立条件，不使用单一高低标签。
10. **证据等级**：原文明确、按材料推演、尚待案例验证。

## 十二、禁用误区

- 把字面数量、来源份额、宫位百分比和传统旺衰当成同一个数。
- 某天干有多个外现，就断定它有多个独立强根。
- 把家里翻出的同一源头沿不同路线重复报账。
- 以一个案例补造完整的清混浊或季节土壤规则。
- 把“清”直接等于富贵，把“浊”直接等于贫贱。
- 把成势直接等于格局高，把根弱直接等于毫无能力。
- 把阴阳制衡点直接当喜用神。
- 只写主做功的好处，不记录做功同时伤害根基的代价。
