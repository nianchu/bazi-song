# 根基、出处与份额计数

## 适用边界

本文件记录“天干寻根基、地支找出处、全局数个数”这一特定象法体系的内部算法。它用于追踪来源、内外投射和份额，不是传统子平各派通用规则，也不是五行旺衰评分。

回答时始终分开：

1. **传统通根**：地支是否直接藏有本干或同类五行。
2. **生扶来源**：某五行能否生扶天干，不等于天干通根。
3. **本体系根基/出处**：允许沿连体、生化、库和“翻出”继续追溯的特殊定义。
4. **份额数**：独立来源或作用层级的计数，不等于字面数量、旺衰或必然人数。

例如卯木生丁，只能在传统体系中称为生扶；卯中不藏丁，不能称丁的直接通根。本体系若称“丁根在卯、根基在辰”，必须标明这是沿 `辰中乙→卯→丁` 追溯的专门术语。

## 三步算法

### 一、天干寻根基

追问台面天干由哪个地支或藏干支撑，是否还能沿连体或生化追到更深的家里源头。

```text
天干外现
← 直接根或生扶节点
← 最终根基/库源
```

天干相同或同五行，不自动代表多个独立源头；必须检查是否共用一个家里根基。

### 二、地支找出处

追问外现地支是否被体系认定为由辰戌丑未等库源“翻出”。“翻出”是该体系的来源映射，不表示库中实际藏有一个完整地支。

### 三、全局数份额

先列台面份额，再列家里投射份额，最后按源头去重。

```text
有效份额
= 台面独立来源
+ 家里向外投射的独立来源
- 已经通过其他路线计入的同源重复
```

核心规则：

> 同一个家里源头可以形成多条外现路线；计算同一个目标时，该源头只能报账一次。

## 家里家外的作用

本体系常以年月为家外、日时为家里，但宫位只帮助区分内部源头和外部表现，不能单凭位置确认现实产权。

- 家里同一源头出现多个表现，通常先合并为一份。
- 家里源头翻到家外，可按规则形成一个外部份额。
- 同一个家里源头已经通过甲路线计入目标，就不能再通过乙路线重复增加同一目标。

## 固定教学例：丁卯 壬寅 壬辰 癸卯

藏干：

```text
卯：乙
寅：甲、丙、戊
辰：戊、乙、癸
卯：乙
```

本体系把日支辰视为家里的共同源头：辰中癸可映射壬癸水，辰中乙可向外映射寅卯木。此映射属于该体系，不是传统藏干的直接等同。

### 为什么卯木算两份

```text
年支明现卯①：1份
辰中乙向外翻成卯②：1份
合计：卯木2份
```

### 为什么壬寅“看起来是两个”

分别计算月柱两端：

```text
月干壬：明现壬①＋辰中癸翻出的壬②＝2份
月支寅：明现寅①＋辰中乙翻出的寅②＝2份
```

因此可把月柱理解为两个层次：

```text
壬寅①＝家外原局明现的一套
壬寅②＝家里辰中水木向外投射的一套
```

“两个壬寅”是份额/层次表达，不是原局真的增加了第二根月柱。

### 为什么丁火是三份

第一、第二份来自两份卯木生丁：

```text
年支明现卯① → 丁①
辰中乙翻成卯② → 丁②
```

第三份来自家外原生寅中的丙火：

```text
月支明现寅① → 寅中丙 → 归入丁火份额③
```

不能再把家里投射的寅②也计作丁④：

```text
辰中乙 → 卯② → 丁②       已经计入
辰中乙 → 寅② → 丙 → 丁×   同一辰源重复，删除
```

所以：

```text
丁火份额＝卯①所生＋卯②所生＋寅①中丙翻出＝3
```

不要表述为“丁卯一个＋壬寅一个＋辰一个”。这把柱、地支和源头三个不同层级直接相加。辰也不是额外的一份丁；辰已经通过卯②进入丁②，再加辰会重复报账。

## 白话类比

把辰视为总部：

- 家外原有卯部门支持丁项目一份。
- 总部辰派出卯部门，再支持丁项目一份。
- 家外原有寅部门携带丙火技术，再支持丁项目一份。
- 总部辰若另以寅的名义申报，仍是同一总部预算，不能再次计算。

## 读盘检查表

1. 当前采用传统通根，还是该体系的根基/出处？
2. 家里与家外怎样划分？
3. 每个台面字的直接来源是什么？
4. 哪些字共用同一个库源或家里源头？
5. 同源投射经过了哪些不同路线？
6. 目标份额中是否把同一源头报账两次？
7. 份额是在说来源、层次还是人物假设？
8. 是否错误地把份额数当作旺衰强度？

## 证据规则

- 对未公开完整定义的“连体、翻出、出处”保留不确定性，不自行补造规则。
- 用人数、婚姻次数、团队层级等现实反馈检验份额法时，先冻结计数结果，再读取答案。
- 单一案例符合不能升级为稳定规则；记录不符合和重复计数争议。
- 对外输出时同时给出传统通根解释，防止学习者混用术语。
