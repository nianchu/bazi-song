# 阴阳制衡点

## 适用边界

本文件记录一种特定象法体系中的“全局阴阳制衡点”读法，不把它冒充所有子平体系的统一定义。公开资料不足以确认原作者的完整判定算法时，应标注“按现有材料作结构化推演”，不能伪装成原作者原话。

阴阳制衡点是传统命理中的功能判断，不是经过现代科学验证的物理能量，也不能单独推出吉凶、疾病或人生层次。

## 一、先区分两层阴阳

### 字面阴阳

- 天干有甲丙戊庚壬为阳，乙丁己辛癸为阴。
- 地支各有固定阴阳属性。

字面阴阳用于识别字的属性，不能靠数量相加直接判断全局是否失衡。

### 运行状态阴阳

- 阳性运动：生长、扩张、上升、释放、显露、向外推动。
- 阴性运动：收藏、下降、蓄积、休养、潜藏、向内收拢。

判断全局制衡点时，优先看哪种运行状态得令、得势并占据主要力量。一个字即使字面属阴，在特定季节和组合中也可能参与强烈的向外扩张运动。例如春季成势的卯木虽为阴支，其曲直生发仍可成为全局阳性运动的一部分。

## 二、定义与公式

> 阴阳制衡点：全局主导运动走向极端时，原局中承担相反必要功能、并能与主势实际连接的环节。

```text
阴阳制衡点
= 主导运动的相反必要功能
× 原局真实存在
× 有根基出处
× 能接入全局
× 有足够力量承担功能
```

这里的乘号表示缺少任何关键条件，制衡的落实程度都会下降，不是数学计算。

## 三、标准判断步骤

1. **找成势**：结合月令、季节、透藏、根气、宫位权重和组合，确定全局真正占优势的力量；禁止只数五行个数。
2. **定方向**：判断主势主要表现为向外生长释放，还是向内收藏凝聚。
3. **找反向功能**：向外过强需要收藏、休养、边界等功能；向内过强需要启动、生发、表达等功能。
4. **查原局载体**：找出哪个字或组合实际承担该反向功能，不能把原局没有的字直接当成已经存在的制衡点。
5. **寻根基出处**：检查其从哪里获得力量，同源透出要去重；表面出现多个不等于地下有多份根基。
6. **核实连接**：制衡环节必须能进入全局路线；孤立、虚浮或被合绊者只能降级处理。
7. **比较力量**：判断它能否承担制衡，还是仅仅存在但被主势持续抽取、泄耗或破坏。
8. **双轴复核**：分别检查“状态阴阳轴”和“五行生克轴”，防止把状态相反误认为五行必然相克。
9. **分层取用**：制衡点只说明一种功能，再分别讨论调候、扶抑、通关、病药、格局和体用；不得直接等同喜用神。
10. **岁运验证**：大运流年可能补强、激活或破坏制衡环节，但必须结合现实反馈验证。

速记：

```text
找成势 → 定升降出入 → 找相反功能 → 查载体
→ 寻出处 → 比力量 → 看损益 → 分层取用 → 岁运验证
```

## 四、必须分开的五种角色

| 角色 | 回答的问题 |
|---|---|
| 阴阳制衡点 | 什么功能能避免主导运动单向走极端？ |
| 五行直接制约点 | 谁在生克关系上直接约束过强者？ |
| 流通出口 | 过盛力量可以向哪里转化和释放？ |
| 根基承载点 | 哪个位置提供来源、容器或承载？ |
| 喜用神 | 在指定取用层次和具体条件下，增加什么功能更可能改善结构？ |

这些角色可能由同一个字兼任，也可能完全不同。不得因为某字是制衡点，就直接宣布该五行为喜用；也不得因为某五行能克旺神，就断定它进入命局一定有利。

## 五、双轴判断：为何“水制衡木”又“水生木”

同一对五行可以在不同分析轴上同时成立：

```text
状态阴阳轴：水的润下收藏 ↔ 木的曲直生发
五行生克轴：水 → 生木
```

因此，水可以承担木势的阴性储备和收藏功能，同时又在五行流通中给木供能。若水的根基很小而木势很强，水可能不是把木压住，而是被木持续抽取。此时应写成“制衡点存在但承载不足”，不能写成“见水必然平衡”或“水越多越好”。

## 六、固定示范：丁卯 壬寅 壬辰 癸卯

以下仅演示用户提供的特定宫位权重体系：年支1%、月支50%、日支1%、时支48%，不作为通行子平定量标准。

### 1. 主势

- 寅木处月支旺点，卯木处时支旺点，另有年支卯。
- 寅卯生于春季，曲直、生长、扩张和输出成势。
- 所以全局偏向阳性运动；这不是把寅卯按固定阴阳属性简单计数。

### 2. 制衡点及出处

- 壬癸水的润下、收藏和储备，与寅卯木的向外生发形成状态上的反向功能。
- 月干壬、日干壬、时干癸最终都要向日支辰中癸水寻找根基。
- 三个天干水是多个表现窗口，不等于三份地下根基；同源去重后，主要依靠辰中这一份癸水。
- 辰位在该权重体系中仅占1%，所以应表述为“水的制衡功能可见，但根基和承载很弱”。

### 3. 全局路线

```text
辰中癸水
→ 翻出壬、壬、癸
→ 生寅、卯、卯
→ 木再生年干丁火
```

同时，旺木还会克、穿或持续消耗辰所代表的承载接口。于是形成：全局依靠辰提供根源，主势又反过来给辰施压。按该体系，辰因此兼有“贵字”和“病字”的双重角色。

### 4. 五种角色落位

| 角色 | 本例 |
|---|---|
| 主导运动 | 春季寅卯木的生长扩张 |
| 阴阳制衡点 | 壬癸水的收藏储备功能 |
| 根基承载点 | 日支辰及辰中癸水 |
| 流通出口 | 木生年干丁火 |
| 直接制约木者 | 金，但原局不见；不能据此直接断“补金” |

丁火是木的输出和结果端，仍属于炎上、外放方向。它可以泄木，却不是本例材料所称的阴性收藏制衡点。

## 七、标准表达与禁用误区

推荐表达：

> 全局以某种运行状态成势；某字承担相反功能，因此可视为阴阳制衡点。但它的根基、连接和力量为某种状态，所以制衡能否落实仍需另判。此结论不自动等于喜用神。

禁止：

- 数阳干阳支与阴干阴支的数量后直接定全局阴阳。
- 把“制衡点”解释成“专门克旺神的五行”。
- 把制衡点、调候用神、扶抑用神、病药和体用混成一个答案。
- 忽略同源去重，因天干出现多个就判断根基很强。
- 见木旺便机械补金，或见水是制衡点便机械补水。
- 仅凭一个制衡点推断财富、职业、健康或人生层次。
